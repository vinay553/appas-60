# Appa at 60

A newspaper keepsake for Appa's 60th birthday on November 13, 2026, recreating the look and headlines of The Times of India front page from November 13, 1966.

Hosted at https://vinay553.github.io/appas-60/ using GitHub Pages from the main branch root. No build step or dependencies. Open index.html or serve the directory with any static web server.

The reading edition uses original headlines, contextual summaries, decorative commemorative advertisements, and two details from the original archive preview. It is not a verbatim transcription. The original front-page preview is available in a keyboard-accessible dialog with zoom. The separate birthday dedication is contemporary.

Source: https://timescontent.timesofindia.com/photo/infographics/priceless-birthday-gift-toi-frontpage/722996

Date-specific public preview: https://api-timescontent.timesofindia.com/api/v1/vintage-papers/1966-11-13

The original preview is 395 × 630 pixels. It includes its original Times Content watermark. Scan, cartoon, and original advertisements © Bennett, Coleman & Co. Ltd. This personal tribute is not affiliated with The Times of India. Display fonts load from Google Fonts; local serif fonts serve as fallbacks.
