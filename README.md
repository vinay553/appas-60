# The Sunday Standard — November 13, 1966

A newspaper reading edition based on The Sunday Standard, Madras, Sunday November 13, 1966, from The Indian Express archive. Seven selected articles, including the editorial A Brighter Tomorrow, with original flood photography above the lead article. Includes a zoomable original scan and the 16-page issue.

Live: https://vinay553.github.io/appas-60/

Buildless HTML, CSS and JavaScript. GitHub Pages serves the main branch root. No installation required.

Each Read more button opens the article reader at article.html?article=<key>#<key>. Transcriptions are embedded directly in the HTML so reading does not depend on JavaScript or a JSON fetch. JavaScript selects the requested article and enhances the collapsed original-scan comparison. articles.json is the transcription source; keep its text in sync with the embedded sections. Reader script URLs are versioned to avoid stale GitHub Pages browser caches. Uncertain passages are marked [unclear], and incomplete transcription coverage is described per article. A Brighter Tomorrow is transcribed in full from the page-six editorial. All 16 locally stored scans remain available in the comparison reader.

## Sources

- Issue and original articles: https://books.google.com/books?id=f5FlAAAAIBAJ&pg=PA1
- Date: November 13, 1966. Publication title on the actual masthead: The Sunday Standard. Edition: Madras.
- Headlines follow the original. Bodies are condensed summaries based on the front-page scan, not verbatim article transcriptions. No later events are presented as news from that morning.
- Original image is stored locally, including its archive markings. The flood photograph and Binaca advertisement use CSS windows into that same scan. Masthead advertisements are typographic recreations.
- Display fonts use Google Fonts with local serif fallbacks.

The previous Times of India reading edition was replaced because this archive provides a substantially clearer front-page scan and more legible reporting. There is no personal dedication or birthday content.
